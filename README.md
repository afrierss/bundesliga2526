# bundesliga2526
Exploring Bundesliga season 25/26 data to train excel skills
Austrian Bundesliga 2025/26 – Excel Analysis
This is a project to train excel skills. It explores match results from the 2025/26 Austrian Bundesliga using Excel.
The database was downloaded from Football-Data.co.uk.
I analyzed Homepoints, Awaypoints, Goals per calendar day, winners etc. I also used PivotTables.
Functions used include SUMIF, COUNTIF, MAXIFS and XLOOKUP.
